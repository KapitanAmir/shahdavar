شهدآور — نسخه حرفه‌ای بازسازی و یکپارچه‌شده

اجرا در ویندوز:
1) Python 3.12 یا جدیدتر نصب باشد.
2) ساده‌ترین روش: START.bat را اجرا کنید؛ اگر وابستگی‌ها نصب نباشند، فایل تلاش می‌کند requirements.txt را نصب کند.
3) اجرای مستقیم: python app.py

وابستگی‌ها:
pip install -r requirements.txt

ساختار اصلی حفظ شده است:
- honeyshop.db منبع اصلی دیتابیس است.
- تصاویر، محصولات، کاربران، کاورها و لوگوی فعلی حذف نشده‌اند.
- database.py منبع اصلی عملیات دیتابیس است.
- سیستم Contact و Banner دیگر در app.py کپی مستقل ندارند و از database.py استفاده می‌کنند.
- Theme سراسری در js/theme.js و css/theme.css مدیریت می‌شود.

قابلیت‌های اصلی نسخه فعلی:
- Theme روشن/تاریک پایدار با localStorage
- منوی سریع سراسری و Responsive
- احراز هویت و Session کاربران
- Username یکتا با قوانین ۸ تا ۲۰ کاراکتر
- مدیریت پروفایل و آواتار
- مدیریت محصولات، دسته‌ها، کاورها و بنرها
- Carousel دسته‌بندی محصولات با سقف ۱۰ محصول اولیه
- نظرات با امتیاز ۱ تا ۵ و وضعیت‌های pending/approved/rejected/replied
- پاسخ مالک به نظر
- پشتیبانی Messenger-like با Reply به پیام
- زمان‌بندی فارسی با timezone ایران
- Contactهای متعدد از یک Platform با آیکن ایموجی/فایل
- About Rich Text Editor با متن، تیتر، رنگ، لینک، تصویر، Resize و Alignment
- پاک‌سازی HTML و جلوگیری از XSS در محتوای Rich Text
- CSRF برای فرم‌ها و درخواست‌های state-changing
- اعتبارسنجی واقعی فایل تصویر بر اساس signature
- امنیت پایه HTTP headers
- شهدیار با خواندن اطلاعات واقعی دیتابیس و fallback providerها

Backup دیتابیس:
فایل‌های honeyshop.db.backup-* نسخه‌های قبل/بعد Migration هستند. فایل pre-audit، نسخه قبل از تغییرات دیتابیس است.

تست:
python tests/smoke_audit.py

نکته امنیتی مهم:
فایل .env پروژه حاوی کلیدهای Provider است. چون این کلیدها در فایل پروژه قرار گرفته‌اند، برای استقرار عمومی بهتر است کلیدهای فعلی Rotate شوند و مقادیر جدید در محیط امن قرار گیرند.

============================================================
ارتقای فروشگاه حرفه‌ای شهدآور - نسخه تجارت الکترونیک
============================================================

این نسخه بدون حذف تنظیمات قبلی، قابلیت‌های زیر را اضافه می‌کند:
- سبد خرید حساب‌محور، تغییر تعداد، حذف، جمع فاکتور و قیمت نهایی
- وزن و موجودی/تعداد محصول
- ثبت سفارش، فاکتور و تاریخچه خرید
- مدیریت سفارش‌ها در پنل مالک
- روش پرداخت «هماهنگی با فروشنده» و ساختار آماده پرداخت آنلاین
- بخش «نظرات» برای نظرهای تازه و بخش جداگانه «نظرات تأییدشده»
- جستجو و ویرایش کاربران توسط مالک با شماره/نام کاربری/ایمیل
- تغییر رمز کاربر توسط مالک
- چت مستقل فراموشی رمز در پنل مالک
- ویرایش/حذف/پاسخ پیام‌های پشتیبانی و ارسال تصویر، فایل، ویدئو و ویس
- مشاهده اطلاعات کاربر فقط از مسیرهای مالکیت
- نوار سبد خرید پایین سایت
- robots.txt و sitemap.xml و داده‌های ساختاریافته Product/Organization برای آماده‌سازی Google Search
- آواتار جدید شهدیار

برای اتصال به Google Search Console:
1) دامنه واقعی را در .env در SITE_PUBLIC_URL قرار دهید.
2) مقدار GOOGLE_SITE_VERIFICATION را از Search Console وارد کنید.
3) پس از انتشار، آدرس /sitemap.xml را در Search Console ثبت کنید.

برای پرداخت آنلاین واقعی، باید درگاه انتخابی و کلید/مرچنت آن در محیط اجرا تنظیم شود؛ بدون اطلاعات درگاه، سایت عمداً پرداخت واقعی را جعل نمی‌کند و سفارش آنلاین را در وضعیت انتظار نگه می‌دارد.

نکته امنیتی: فایل .env واقعی را عمومی یا در Git منتشر نکنید.
